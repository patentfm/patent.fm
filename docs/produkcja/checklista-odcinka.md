# Checklista odcinka — jeden tydzień, jedna apka

Wydrukuj albo skopiuj do zadania. Odcinek uznajemy za zamknięty, gdy odhaczone jest wszystko
z sekcji „Piątek”.

---

## Poniedziałek — zakres

- [ ] Pomysł wyjęty z backlogu (`docs/produkcja/backlog-pomyslow.md`)
- [ ] Scenariusz reklamy napisany **przed kodem** (`szablon-scenariusza-wideo.md`)
- [ ] Zakres zamrożony: dokładnie 3 funkcje, spisana lista rzeczy odrzuconych
- [ ] Pre-mortem: „jest piątek, odcinka nie ma — dlaczego?” (3 powody + jak je ubijamy)
- [ ] Nazwa, domena/slug, repo z szablonu startowego

## Wtorek–środa — budowa

- [ ] Funkcja 1 działa i jest wdrożona
- [ ] Funkcja 2 działa i jest wdrożona
- [ ] Funkcja 3 działa i jest wdrożona
- [ ] Dane demonstracyjne przygotowane (demo ma wyglądać na żywe, nie na puste)
- [ ] Zero nowych bibliotek spoza stałego stacku (jeśli musiała wejść — notatka do przeglądu sezonu)

## Czwartek — wdrożenie i nagranie

- [ ] Apka pod publicznym adresem, działa na telefonie
- [ ] Analityka i podstawowe SEO/OG na miejscu
- [ ] Nagrane demo trzech funkcji (surowe ujęcia, każde po kilka podejść)
- [ ] Nagrane ujęcia fabularne (cierpienie, opinie „klientów”)
- [ ] Slajdy z decku wyeksportowane

## Piątek — publikacja

- [ ] Montaż 90 s + wersja krótka 20–30 s
- [ ] Napisy (obowiązkowo)
- [ ] Miniatura
- [ ] Wideo opublikowane, mamy identyfikator (YouTube ID / Vimeo ID)
- [ ] Odcinek na patent.fm: nowy plik w `_odcinki/` (patrz `docs/strona.md`)
- [ ] Repo publiczne, README z linkiem do odcinka
- [ ] Newsletter „Patent tygodnia” wysłany
- [ ] Wrzutki: TikTok, Shorts, Reels, LinkedIn
- [ ] Kulisy odchodzą do folderu materiału kursowego (z tego powstanie kurs)

---

## Ship or kill

Jeśli w **czwartek rano** nie ma działających trzech funkcji:

1. Tniemy do dwóch i dowozimy, **albo**
2. Odcinek wychodzi jako **„porażka tygodnia”** — rozbiór, co poszło nie tak i czego to uczy.

Czego **nie** robimy: nie przesuwamy publikacji. Jedno przesunięcie zamienia się w trzy,
a trzy kończą projekt.

---

## Po sezonie (8 odcinków)

- [ ] Przegląd: średni czas produkcji, co zjadło najwięcej godzin
- [ ] Decyzje o zmianie stacku (jedyny dozwolony moment)
- [ ] Materiał kursowy zmontowany z kulis
- [ ] Dwa tygodnie przerwy — w kalendarzu, nie „jak wyjdzie”
